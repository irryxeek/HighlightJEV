# REZE Direct：固定 QV100 定位对照结果

日期：2026-10-30。状态：100/100 次推理完成，零请求重试，预测冻结后已完成 CPU 评价。

## 1. 结论

**换成 REZE 论文的 Direct 协议后，没有出现一致的定位提升。** 完整100条上，首个区间的 R1@0.5 从42%降至39%，R1@0.7从28%升至30%，MR mAP从24.72升至26.48。多区间任一命中的 recall@0.5为44%，不能作为R1报告。

旧版52个有效响应反例中，9个被首区间修正；同时15个原本命中的样本退步。部分边界更准确，但过短、过宽、重复事件切分与生成顺序的问题仍然存在。输入更密、开销更高，没有据此证明 grounding 整体更强。

## 2. 实际替换内容

沿用此前冻结的完整100条 QVHighlights **train开发样本**、视频、query、顺序和 Qwen3-VL-8B-Instruct BF16 权重。没有筛选52条反例或根据指标换样本；这不是独立测试集。

| 项目 | 旧自定义 Direct | 本轮 REZE Direct 协议重建 |
|---|---|---|
| 视频输入 | 整视频64帧 | 整视频2 FPS，实际242–300帧；95条为300帧 |
| 时间信息 | 原生视频时间信息 | 原生视频时间信息，保留实际PTS |
| 空间处理 | 512×320外框、32倍数 | 沿用相同缩放规则 |
| 任务输出 | 单个最佳连续区间，允许弃答 | 所有匹配区间；重复出现分别列出；不确定时给最可能区间 |
| 输出形式 | 结构化JSON、严格合法性检查 | 每行 `[start, end]`，宽容解析，最多保留10个 |
| 解码上限 | 2048 token | 128 token，greedy，关闭thinking，无system prompt |
| 运行 | TP=1、8192上下文 | TP=2、32768上下文；每10条一个冷worker |

依据 [REZE附录A.1/A.2/E](https://arxiv.org/html/2608.04480v1)重建 Direct timestamp-generation 对照。它是**整视频一次调用生成时间区间**，并非 REZE 的局部 Yes/No 密集验证算法。本轮没有记忆、比较器或回看。

公开材料未完整提供Qwen3 Direct的视觉尺寸、抽帧相位与区间置信度导出实现；本地采用半秒格中点采样、已有空间缩放，并按生成顺序赋 `1/(rank+1)` 作为保序导出分数。该分数不是模型置信度。多个设置同时变化，因此这是方案替换对照，不能把变化归因于某一个改动，也不宣称复现了论文test成绩。

## 4. 反例变化与具体案例

按首区间IoU≥0.5计：两轮都命中27条、旧失新中12条、旧中新失15条、两轮都未命中46条。12条新增命中中，9条属于旧52反例，3条属于旧技术失败/未运行。若允许查看任一输出区间，旧52反例有12条得到覆盖，但其中3条仍不是首区间命中。

新版98条非空预测中有59条首区间IoU<0.5；再加2条空预测，完整100条共有61条未达首区间门槛。以下是基于既有GT的描述性例子，不是新增独立人工视觉审阅结论。

| qid / 查询简述 | GT（秒） | 旧预测 → 新预测 | 解读 |
|---|---|---|---|
| 10293：亮黄外套警察抓捕 | [66,98] | [65,130] → [65,96]；IoU 0.492→0.909 | 缩短冗余尾部，边界明显改善 |
| 5466：展示视频编辑软件 | [0,8]、[48,62] | [38,57] → [0,7.5]、[38,61]；首区间IoU 0.375→0.938 | 找回先前遗漏的一次出现 |
| 5981：儿童穿行金属游乐设施 | [28,68] | [27,68] → [27,39]；IoU 0.976→0.268 | 只保留短片段，事件范围不足 |
| 448：鸡在鸡舍中 | [92,112] | [130,145] → [1,150]；IoU 0→0.134 | 旧版错时段，新版几乎覆盖全视频，仍未定位成功 |
| 7345：三位女性在客厅聊天 | [124,144] | [125,148] → [0,6.5]、[2,14.5]、[124,149] | 新版第三段IoU=0.8，但首段IoU=0；不能把任一命中当R1 |
| 9319：飓风新闻发布会 | [20,80]、[82,142]、[144,150] | [20,150] → [20,149]；IoU 0.462→0.465 | 仍把分段GT合并成大区间，不能仅凭低IoU断定完全没识别事件 |

共生成139个有效区间：86条输出1段、12条输出多段、2条无有效段。5条仅有后续区间命中@0.5：2781、7345、5984、658、8105。两条达到128 token上限（2781、8105），各保留9个完整区间，末尾不完整片段不补全、不重试。解析过程没有发生端点倒序修正或越界裁剪，只有两个零长度区间被删除。

这些结果支持继续区分事件完整性、边界、重复事件切分和输出顺序；**尚不能证明密集输入或某一句提示是退步原因**。旧标注范围/多次出现问题也不会因为更换Direct提示自动消失。

旧轮记账token为494,459，GPU生命周期为361.064442秒。本轮整场token约4.66倍、GPU成本约11.94倍；两轮完成数、输入帧数、TP和冷启动次数不同，这不是等输入硬件速度对照。该开销下，目前没有证据支持宣称更高效。

本轮使用独立账本，旧QV、TVSum及其他Direct额度没有转入。CPU准备、11项契约测试、评价与整理均没有新增实验模型调用。
