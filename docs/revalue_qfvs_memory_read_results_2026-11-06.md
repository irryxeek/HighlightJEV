## 解释边界

每查询只在84个固定候选中选原生2%摘要（43–73个5秒片段）。池中保留全部旧B0摘要片段，均匀补充其余候选。它检验固定候选池内的记忆读取，不代表完整长视频搜索。
Uniform是完整视频网格上的旧规则CPU参照，不受84候选池约束。B0来自旧Qwen3-VL-8B密集REZE，模型和覆盖不同于新27B三组，仅作系统参照；二者没有新模型调用。
四视频各用64个全局旧帧、8次建库调用形成共享事实库。事实库极稀疏，不能覆盖所有查询事件；没有重新采样、回看或新增视觉搜索。
D只看84个候选帧，F/F-read还通过记忆接收64个全局帧的信息。因此F−D同时包含额外观察信息，不能称为纯记忆效果。主比较F-read−F固定同一库和视觉来源。
读取锚点仍是旧B0最高5个片段，未按查询词额外做语义检索；窗口换成原生5秒。任务OR语义和摘要长度对三组相同。
模型建库仍产出五类V字段以保持写入器一致，但本轮任何选片输入均不读取V；没有价值模块对照。
失败、弃权、未尝试均保留完整40分母并使用冻结B0回退，合法输出率和回退单列。没有把回退当作新模型预测。
只有4个视频cluster，查询并非40个独立视频。区间为开发诊断描述，不能作未见视频泛化或全180条测试结论。
