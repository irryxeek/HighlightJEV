## 4. 先行审计揭示的限制仍存在

以下是既有审计与新候选的交叉案例，非随机精度样本。图像依据来自助手检查旧缓存帧，未形成独立人工标签；不能将案例数换算为总体准确率。

1. **动作误判仍被沿用。** GsAD1KT1xo8的132–134秒，先行审图显示撑栏及身体坠落／摆动，未见滑板；C、V仍引用g07.f01并描述滑板滑杆，支持旧理由。来源引用合法未解决事件归属。旧文字造成偏置是待检验解释，不是已确立根因。
2. **错误前提可能被详细价值理由放大。** 同视频98–100秒，两组都继续把推车入水描述成男孩跳河；V又以“更戏剧化、意外”为由给出明确优先。明确判断更多不必然更可靠。
3. **局部解释有改善，选择未变。** i3wAGJaaktw的22–24秒，C质疑看不到锁扣固定；V指出笼内是白毛巾，没有狗的画面支持“把狗关进去”。V的解释更贴近先行审图，但两组都选择该段。
4. **缺少支持与反证仍有混淆。** WxtbjNsCQ8A的200–202秒，两组都正确指出没有可见滴落，却将旧理由及state判为contradicted。“未看到滴落”本身不足以证明滴落不存在；state又与自身“可见盖子”的观察描述混杂，不能记作已经验证的正确报警。

此外，原响应全部finish_reason=stop，**没有max_tokens导致的整条截断，但解释字段的长度限制确实构成问题**：C有23/50、V有30/50条触及至少一个字符上限，分别30、40个字段到达上限；其中25、39个字段无句末标点。无标点不是自动无效标签，不过实读存在“...priority ”、“...The ”等未完成短句。这个限制对两臂相同，但V更频繁触及，不能称为已排除输出表达干扰。

## 5. 验收判断与下一步边界

技术门槛通过：两组100%合法，预算和输入契约满足。科学上目前支持的是“详细准则可以改变部分比较的可判定性”，尚未证明事实核验可靠、已有错误赢家得到纠正或最终mAP改善。

建议先保留这100条和原输出，不立即把报警接成自动删除／替换。后续优先处理两件事：

- 用已存输出做不新增模型调用的语义分类，进一步区分事实描述、原理由、缺少证据和真实反证；修复解释字段表达限制的方案另行冻结，不能改写本轮响应。

本轮没有执行修正器、没有扩展其余30视频；任何新模型条件均需明确范围与调用上限后再运行。
