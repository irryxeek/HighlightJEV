## 展示内容

1. 当前范围的冻结原生 Top-5 mAP，以及单视频 Top-5 AP。
2. **评价实际 Top-5**与**模型原始推荐**分别展示。保存的原生评价顺序与分数直接来自已有 JSON；同 tier 推荐保留并列，不补造严格优劣。
3. 两个原视频播放器支持方法切换、两类选片列表、区间跳转与终点暂停。
4. 实际模型输入帧、真实 PTS、原源帧 ID；事实／推荐引用可定位帧。
5. 各组实际读入的事实，FV 实际读入的五类价值证据；完整事实库将未读入条目标出。
6. 原始响应、实际发送提示、输出契约、引用去重、来源路径及哈希，可下载单视频查看数据。

TVSum 是通用高光任务，当前使用 UMT Top-5 mAP；不套用 QV 的 GT 时间区间、IoU 或 verifier 报警。未重新读取 GT 或计算模型性能。
