## 1. 修复范围

v2 的全局 `state=insufficient` 覆盖了已看清的局部事实；同时，“滑板滑杆”可在滑板活动本身未知时独立获支持。本轮 `R_keep_v3` 修复这两个接口问题：

1. 每个原子和前提各有 `observability=established/uncertain`。该字段判断本条正向观察是否看清，不表示旧理由为真、整段看清或高光价值突出。候选级 state 不再覆盖任何原子。
2. 由原理由的语义构造固定依赖图。未知前提只让依赖动作 unknown，不成为反证，不影响没有依赖关系的颜色／位置等事实。既要验证前提已支持，也检查引用与目标动作存在共同局部时间点；开关前后位置另要求 OFF 严格早于 ON。

原模型提案、依赖前的局部规则判断、依赖后的结果及阻断原因分别保存。仅有模型填写的 true／event_sequence 或两个 PTS 不是视觉真值。

## 2. 原子及依赖输入

保留 v2 的原 22 个 claim_atoms，文字跨度、hash、实体、谓词和含义逐项不变。新增 16 个前提，单独统计，不把分母从 22 偷换成 38：

- 蜂蜜滴落：液体在盖子处可辨认；纹理可见不能独自证明滴落。
- 狗被关入笼子：狗在笼内，以及同一笼门前后关闭状态。
- 骑行：可识别的自行车／第一视角机械线索；不要求 POV 骑行者必须露脸。
- 车辆驶过：同一车辆可识别，车身类别判断和运动可分开。
- 压缩机／充气：实际开关 OFF／ON 位置及顺序、轮胎变化；字面 0／I 标记不等于当前开关状态。
- 滑板与栏杆：滑板可见、人与板的对应接触、栏杆可见、板与栏杆接触；滑杆原子还依赖滑板活动原子。
- 男孩与购物车／河流：人物和车可识别、跳跃配置或人物与水的接触，不能以车落水替代人落水。

这是从原理由文字设计的保守操作性证据标准，不保证穷尽现实中所有正确动作线索。例如遮挡、其他视角或其他可用线索可能导致 false unknown。前提本身只是待检查命题，输入中不含应判真假的答案。助手已知开发案例背景，不宣称盲化或自动解析能力。

图定义按语义谓词／取值查表，无视频 ID 决策。CPU 校验须重新生成并精确核对前提、边及时间约束，防止通过删除边、换主体或制造环路绕过依赖检查。
