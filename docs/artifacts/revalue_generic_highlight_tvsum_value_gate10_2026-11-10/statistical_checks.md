# 统计解释检查（按已冻结方案核验）

本轮按 academic-research-suite 的统计解释指南核验11/11类风险。清单在推理进行期间整理，未读取新预测或评价结果；没有修改开跑前冻结的范围和分析方法。结果报告应结合实际数据引用此清单。

1. Simpson／总体与分组：同时报告完整十视频均值、逐视频差值、提升/下降数量；不以多数视频上升替代均值。
2. 生态谬误：按视频为统计单位，不从总体mAP推断某价值规则的准确率。
3. 选择偏差：固定全部旧val10；这些开发样本已见，不能声称独立测试。
4. 条件化／碰撞变量：不按新分数、成功结论或某类规则状态筛选评价子集。
5. 基率：沿用UMT各标注者个人中位数正例定义，辅助正例比例不作独立语义准确率。
6. 均值回归：规则开发参考过失败案例；报告全部10条与冻结对照，不将某极端案例恢复等同总体机制验证。
7. 幸存者偏差：保留全部目标；失败视频零失败信用，不能只报告成功子集。
8. 多重比较：同时报告预定三组差值与辅助项；三个95%区间是分别的描述区间，不是联合置信保证，不挑有利项。
9. 分析路径：完整清单、提示、评价、主/次比较、随机种子与预算在运行前冻结；无按结果调整。
10. 因果归因：规则包包含三条问题与聚合总则、提示长度及注意力变化；不能归因于单一价值维度。与无背景/REZE比较条件更多。
11. 反向／反馈污染：预测冻结后才读标签评价；研究者已有开发反馈，不能声称没有测试集适配风险。
