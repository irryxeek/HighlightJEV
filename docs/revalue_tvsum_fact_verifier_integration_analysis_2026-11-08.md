# 事实记忆＋后置价值 verifier：接入分析与下一步

日期：2026-11-08。基于固定 10 条 TVSum 开发视频，复用 50 对候选、100 条旧 C/V 响应完成 CPU 接入；没有新增模型推理。

## 1. 当前实现与用户要求的对应关系

流程为：**1 fps 观察 → 事实记忆 F-local → 初始 Top-5 → 事实记忆＋候选局部旧帧 → verifier → 保守替换 → 最终 Top-5**。

候选生成和 verifier 均不读取价值记忆库。事实记忆记录事件、时间与来源；详细五维价值标准只在 V verifier 中使用。初始选片仍需判断一般的重要程度，因此“价值模块后置”指详细判据和验证位置的调整，不代表初选完全没有隐含价值判断。

旧 C/V 实验已经符合这个输入结构，但此前仅分析核验输出，没有接入最终选片。本轮新增确定性接入：只有明确偏好备选、两侧事件与贡献均获支持、片内引用对应时才替换。证据不足、并列、不可比较和契约不满足时保持原选择。原选择理由被否定，不能单独作为删除依据。

## 2. 完整 10 视频结果

指标为 TVSum Top-5 mAP（%），主导出为固定排名位置替换。

| 方法 | mAP | 相对 F-local | 接受替换 |
|---|---:|---:|---:|
| F-local，仅事实记忆选片 | 56.6465 | — | — |
| F-local＋普通 C verifier | 59.8750 | +3.2285 pp | 5/50 |
| F-local＋详细 V verifier | 59.7396 | +3.0931 pp | 5/50 |

**事实：后置核验改善了这批开发视频的最终指标，但详细 V 比普通 C 低 0.1354 pp，尚未证明详细价值标准的额外收益。** C 本身已有通用观看贡献问题；此处不是“有价值判断／完全无价值判断”的对照。

C 相对 F 有 3 个视频提高、7 个不变；V 有 4 个提高、6 个不变。V−C 的视频配对描述性 bootstrap 95% 区间为 [-0.5118, +0.0875] pp。样本已反复用于开发，这不是确认性显著性证据。

同批参照 D-1fps 为 69.2479，选片前使用价值记忆的 FV-local 为 59.7007。V verifier 相对 FV-local 只高 0.0389 pp，且调用结构不同，不能据此证明价值模块后置优于前置；与 D 的差距也仍存在。

## 3. 全部替换及收益集中性

以下覆盖两组全部 10 次接受动作，合并后为 7 个不同候选对。片段编号为冻结记录中的 clip ID；单次差值是该视频只执行此项替换时的 AP 变化，不能相加作为联合贡献。

| 视频／候选对 | 原片段→备选 | 接受组 | 单独替换 AP 差值（pp） |
|---|---|---|---:|
| WxtbjNsCQ8A / pair01 | 1→38 | C、V | +7.0521 |
| XkqCExn6_Us / pair02 | 44→39 | C、V | +2.5000 |
| XkqCExn6_Us / pair04 | 2→70 | C | +2.4826 |
| XzYM3PfTM4w / pair00 | 0→24 | C、V | +21.9028 |
| XzYM3PfTM4w / pair03 | 26→27 | C | **−0.9063** |
| gzDbaEs1Rlg / pair04 | 118→73 | V | +0.0903 |
| XzYM3PfTM4w / pair04 | 41→22 | V | +0.3194 |

两组有 3 次共同替换，其中 XzYM3PfTM4w 的主要替换贡献很大。普通复核虽然总体提高，仍有一次单项负收益。详细价值复核在 XkqCExn6_Us 少接受一次有益替换，相对 C 下降 1.7361 pp；另外两个视频的小幅提升不足以抵消。

这些是与标注指标的对应关系，不是独立人工语义核验，不能把接受动作都称为“纠正错误”。

## 4. 排序导出与并列分数

主导出保持原 F-local 完整排序，以备选交换对应锚点的排名位置，再用单调排名编码供评价。对照的完整排序和每位标注者 AP 与原 F-local 完全一致；排名编码不是新的模型评分或概率。

另一个预先固定的导出方式只交换原分数，得到 C=59.1698、V=59.0344；两者相对 F 分别提高 2.5233、2.3878 pp，V−C 仍为 −0.1354 pp。

两种导出差异来自 WxtbjNsCQ8A 的 clip 1 与 38：原分数约为 0.7310585845 和 0.7310585801，转成评价器 float32 后相同。因此仅交换数值不能实现已经接受的候选替换。两种结果同时保留，不据指标高低选择报告口径。

## 5. 已确认、未解决与下一步

**已确认：** 仅事实记忆＋后置 verifier 已能输出并评价完整选片结果；旧响应可复用，无需重复模型调用。16 项 CPU 回归通过，官方 UMT 与独立指标核对通过，406 份历史绑定不变。

**尚未解决：** 契约合法与引用对应不保证视觉事实真实。本轮旧 C/V 响应早于原子可观察性、动作前提依赖的 v3 修复；没有把只覆盖 8 对的 v3 输出混入 50 对。当前结果不能归功于 v3，也不能证明“证据不足被当成反证”已经在语义上彻底解决。

**待检验假设：** 普通候选复核可能已提供大部分收益，详细价值标准是否有帮助取决于事实支持和可比较性。当前小样本差值不支持直接下结论。

后续保留 F-local、F+C、F+V 三组，继续使用纯事实记忆；价值判断作为 verifier 的一个条件，而非重新加入选片前价值记忆。先统一两组的原子可观察性与动作依赖接口，再在未反复审查的固定样本上比较最终指标、误替换和弃判率。普通复核是必要对照，不能只比较 F 与 F+V 后把全部收益归于价值标准。本轮未启动新的模型条件或扩样运行。

## 6. 成本与可审计产物
