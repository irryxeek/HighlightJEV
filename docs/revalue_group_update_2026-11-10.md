# ReVALUE 组会汇报内容

来源：本会话最近两段汇报；用户随后要求据此制作PPT。统计截至2026-11-10，承接11月3日组会安排。

本周主要围绕“五维价值能否改善高光检测”开展实验。完善了事实记忆、价值记忆和候选核验流程，并在 TVSum、QFVS、Mr.HiSum 和 SVHighlights 上进行测试。针对通用高光任务，借鉴 REZE 实现了结合全片背景与具体五维标准的窗口评分方法，完成8B和27B模型在 TVSum 全50条视频上的对照。修订版的 Top-5 mAP 分别为55.96和56.26，REZE 8B为54.89；目前有平均分提升，但尚未确认稳定收益。

当前主要问题是：模型容易把“有一定观看价值”判断为“值得优先保留的高光”，导致品牌展示、普通场景和重复内容得分偏高。针对这些失败案例，将评分目标收紧为“对视频主线有关键贡献”，最新8B版在后40条视频上的 Top-5 mAP 达到55.80，高于同范围 REZE 的53.29，但置信区间仍跨0；在 Mr.HiSum 10条视频上的迁移也未改善主要mAP指标。下一步先补齐同版本全50条验证，再重点检查关键事件漏选、重复内容占位及证据不足的问题，判断哪些需要改进决策规则，哪些需要通过回看补充证据。

## 必须保留的边界

- 全50条修订版与最新关键贡献版是不同版本；最新版本仅40条完成，补齐10条的worker初始化失败，新增评分0次。
- 旧10条与新40条的混合版本CPU汇总尚未完成；不能写成已获得新结果。
- TVSum数据为已用开发样本；全50不是独立官方test50。
- 27B条件缺少同模型REZE基线，不能将所有模型差异归因于规则。
- 单token评分不能说明模型实际使用了哪条价值规则。
- 完整Agent闭环、定向补证、ASR和边界修正尚未验证。
