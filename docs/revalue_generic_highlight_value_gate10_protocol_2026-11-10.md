## 修改内容

现有系统没有五维数值权重；本次将用户要求落实为证据门槛与最终判定规则，不引入加权分数。

1. 普通微笑、礼貌说话、人名、台标、品牌可读性、普通风景可以是可见事实，但不能单独建立值得保留的观看贡献，也不能靠多个弱线索累加成高光。
2. 具体收紧 I2／E2／S2：信息需要对主体或过程有实质贡献；情绪需要显著且与事件有关；感官价值需要具体揭示、变化或有诊断意义的视角。
3. O2／I2／E2／A2／S2 中任一项有充分的局部证据支持即可判 Yes。无需同时具备动作、情绪、结果，也不要求没有比较对象时证明优于其他片段。
4. 只有适用路径均缺少充分贡献证据时判 No，并说明最有可能成立的路径为何仍不充分。其他维度缺失不能推翻已经成立的贡献。unknown 不自动算支持，也不算反证。

这是按用户要求同时实施的一个规则包；不能分别归因于“降低普通线索权重”或“提高判 No 门槛”。没有代码强制 Yes、按规则数量投票或修复模型输出。允许负结果和执行规则失败。
