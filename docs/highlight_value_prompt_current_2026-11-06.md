# 当前高光价值提示词：已有细化与尚未验证的部分

## 已经写进提示词的内容

当前TVSum流程及本次Mr.HiSum迁移使用五类**可选**价值视角，并非只给模型五个名称。

| 维度 | 当前要求模型寻找的可见证据 |
|---|---|
| outcome／结果 | 关键结果、完成、失败、转折、状态变化 |
| information／信息 | 理解视频所需的关键步骤、答案或新信息 |
| emotion／情绪 | 相关人物或群体可见的情绪变化、异常强烈的反应 |
| action／动作 | 有辨识度的动作、技巧展示、动作完成或有意义的失误 |
| sensory／感官表现 | 具有观看价值的突出可见事件或变化；不能只因衣服颜色判断 |

原文定义可见建库提示（本地资料：`$MERIT_ROOT/experiments/revalue_mrhisum_memory_read_v1/memory_prompts.py:3`）；选片阶段还使用相对价值规则（本地资料：`$MERIT_ROOT/experiments/revalue_mrhisum_memory_read_v1/prompts.py:121`）。

建库先写可见事实及来源帧，再给每个价值字段写状态：

- `supported`：引用本次响应中清楚可见的事实，并给出具体的`why_watch`。
- `unknown`：说明缺少什么证据；看不清不能当成不存在。
- `not_applicable`：这个视角在当前内容没有有用的判断作用，引用置空。

提示同时要求：不能假设尝试已经成功；没有音频时，人物开口不等于已知发言内容；衣着、人数或外貌本身不能证明高光价值；不强求五类都成立，不虚构因果。事实约20词、观看理由约12词的要求主要控制输出长度。

## 选片时如何使用

选片提示要求比较**同一视频内的相对贡献**：这个时刻比其他已观察内容多提供了什么结果、信息、技巧或反应。出现人物、物体或动作只是事实；`supported`是模型提出的价值证据假设，不是重要性分数，也不是必须选中的指令。允许同分和弃权。

例如，“有人在运动”只能证明动作存在；若要给出动作价值，需要明确可见的特殊技巧、动作完成或有意义的失误。这是上述规则的解释示例，不是本轮新加入提示的few-shot示例，也不是经过人工验证的实验案例。

## 本轮实际验证范围

Mr.HiSum固定40视频的D、F、F-read共享上述选片规则。共享建库仍输出F/V完整记录，但F和F-read只读取**事实记忆F**，不把显式价值字段V送入选片；两者仅改变事实读取策略。不要将它们称为新的价值提示消融。

TVSum此前原40视频中，F的Top-5 mAP为52.6220、FV为50.6473；不能据此声称显式V记忆已带来收益。新F-read为54.4187，较F提高1.7967个百分点，但配对95%区间跨0。以上是已有开发结果，本次未重跑。

## 目前还不够细的地方

当前主要是每类一句定义、证据引用、禁用推断和相对比较规则；还没有系统的类型专属正反例、情绪强度等级、动作难度量表、重复事件对比模板或独立人工价值真值。是否需要这些细化及能否提高检出，需要后续单独对照；本轮固定提示，避免与读取策略混在一起修改。
