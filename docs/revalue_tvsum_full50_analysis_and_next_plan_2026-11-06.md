## 3. 本次离线分析新增了什么证据

### 3.1 价值已经生成，但约一半supported没有进入最终输入

统计覆盖完整新40、320组建库，不按成绩筛选。

| 内容 | 原始保存 | 最终输入 |
|---|---:|---:|
| 事实F | 735 | 445，60.54% |
| supported价值 | 678 | 335，49.41% |
| unknown价值 | 33 | 33 |
| not_applicable价值 | 889 | 880 |

丢失的343条supported中，**341条因引用的事实不在active F，只有2条因V自身token预算**。因此，“把NA删掉就能恢复大多数价值证据”不符合实际来源链。F按每组首条保底、组间轮流装入完整条目；这种顺序可能保留介绍而漏掉动作结果，但是否影响性能仍待对照。

五维supported原始/保留数：outcome 37/13、information 162/73、emotion 52/25、action 256/139、sensory 171/85。这描述的是模型输出及装箱，不是五类真实高光的检出率。

### 3.2 当前V缺少明确的“与谁比”

建库每次只看8个稀疏时刻，输出`state / source_fact_ids / why_watch / missing_evidence`。实际V没有`contrast_fact_ids`；关系仅为PTS先后/重叠，没有经过语义核验的因果事件图。

相对价值规则虽已写入最终选片提示，但输入V仍可把“片头提供主题”“logo有视觉特色”记为supported。**存在价值线索、这条线索有证据、它比另一时刻更值得选，是三个不同判断。** 当前前两项容易被用于推导第三项。

新40全部200个推荐中，理由出现title/logo/lower-third/caption/introduc等文本线索：F为7个，FV为13个；位于视频前10%时段的推荐为29→35个。词匹配不等于片头真值，前段也不等于低价值；这些只是待审查模式，不作为后续选样或过滤规则。

### 3.4 模型推荐与实际计分存在可复现的导出偏差

原导出先按模型tier排序，同tier使用B0顺序，再分配B0原分数多重集。B0同分可让评价器重新交换跨tier顺序，甚至让推荐项掉出Top-5。

| 新40上的检查 | F | FV |
|---|---:|---:|
| 实际Top-5成员不同于预期推荐 | 4/40 | 2/40 |
| 被挤出实际Top-5的推荐项 | 6/200 | 5/200 |
| 排除合法同tier重排后，实际顺序仍不一致 | 10/40 | 6/40 |

例如`WxtbjNsCQ8A`：F推荐`[35,43,100,18,117]`，实际计分`[35,38,117,37,60]`；FV推荐`[35,43,100,18,8]`，实际`[35,38,60,37,36]`。这是工程上可确认的表达损失，但出现视频不多，不能据此解释全部退步。旧评价符合当时冻结协议，保留原结果。

### 3.5 输入覆盖和对照仍有限制

- **可选空间受旧帧限制。** 新40只开放3492/4387个2秒格，微平均79.60%，逐视频平均86.29%，最低43.69%。准确说法是“能选原Top-5以外、且有局部旧帧支持的片段”。最差的两个案例也存在全覆盖者，因此覆盖不足不是所有退步的解释。
- **缺同条件D-relative。** full50只有F/FV；旧D没有相对规则，B0是历史8B密集评分。F低于B0不能独立证明记忆无效、27B更差或事实压缩有害。
- **F/FV输入对照成立。** 新40实际发送提示去掉附加V后40/40一致；共同帧、choice表、schema与输出上限一致。V平均914.85token，F平均985.75token，因此FV−F还包含文本长度和注意力改变。
- **机械引用不是语义绑定。** F/FV分别有39/41个推荐只引用非局部事实，29/15个无事实引用；所有推荐另有合法局部帧锚点。远处事实可以是上下文，空事实引用也可以直接看图，不能一律判错或自动删除。

## 4. 下一步按这个顺序推进

### P0：先检查导出忠实性，不调用模型

本轮已完成推荐→预期顺序→原生Top-5的全new40核对。下一步CPU工作是为原50条补一个**独立的rank-faithful导出分析**，固定规则后一次性应用全部视频及两臂：

1. 从已保存的groups恢复原“tier优先、同tier按B0”的完整顺序；不阅读成绩来决定排序。
2. 对有推荐的结果用严格单调、float32可区分的秩分数表达该顺序；不改变模型tier判断，不增删推荐。合法弃权和技术失败仍保留原B0。
3. 用同一官方评价器计算独立诊断列，同时保留原native及stable-tie列。不得按视频选择表现更好的导出，不覆盖旧预测或报告。
4. 检查推荐覆盖、跨tier顺序、空推荐、少于5项、边界同分和float32碰撞。该检查通过只说明导出忠实，不说明高光判断正确。

这是**后处理条件变化**，不是新的模型预测，也不是价值模块改进。若差值变号，优先明确报告依赖导出规则，不宣布价值已被证实有效。本轮尚未执行这项反事实计分。

### P1：补完整new40的D-relative，建议新增40次选片

**研究问题：在相同稀疏视觉输入与相对高光任务下，F和FV是否比不附文本记忆更好？**

| 条件 | 输入 | 新调用 |
|---|---|---:|
| D-relative | 同一旧帧、choice表、原Top-5提示和相对规则；不提供F/V文本 | 40 |
| F-relative | 冻结的既有输入与输出 | 0，复用 |
| FV-relative | 冻结的既有输入与输出 | 0，复用 |

沿用运行目录`rows.json`的完整40视频和原顺序，不只跑大跌案例；不用标题/类别/GT选样。模型仍为同revision的Qwen3.8-27B，TP4/PP1、相同原生处理器和像素/PTS、32768上下文、1536输出上限、同采样参数。只移除memory段；D的fact引用名单为空是没有文本记忆的必要契约差异，需要明确记录。VALUE_RUBRIC和RELATIVE_VALUE_RULE仍在D中，不能把D变为更简单的另一任务。

CPU审查后才能启动：逐条核对提示差异、像素/PTS、可选域、schema、GT隔离和实际上下文；另建D运行目录与源码快照。冻结D原始预测并确认退出后再评价，不能修写旧F/FV。

主新增比较为**F−D-relative**；FV−D为辅助，FV−F保留既有结果。以视频为单位配对bootstrap，报告全40分母、区间、均值/中位数、逐视频方向；不把800个标注者评分或200个片段当独立样本。原native为历史可比主口径，P0的新导出对三臂统一作为机制诊断，不能择优选口径。

资源建议：40次正式请求，每视频一次，零自动重试、零额外smoke、零重新建库；首条正式请求兼作健康观察。一组空闲四卡、一个worker，按现有选片均值38.52秒估计，含加载约30–45分钟，约0.9–1.1M token、2–3 GPUh。以上是估计，不恢复用户已取消的任意总token/GPU硬额度，也不占用任何旧轮次额度。资源不足时等待，不能只将D换成8B后与27B F/FV归因。

缓存复用只减少本轮新增成本；F/FV作为独立方法，仍分别计入每视频8次初始化及1次选片。F−D包含额外分块观察、文本整理和调用成本，不解释为纯记忆格式的因果效应。

质量条件：预计40份输出；若技术失败，保留全分母与B0回退，不重试、不删样本；至少38/40合法才进入方法解释。系统性输入/来源错误或模型服务失败时停止并报告。进程存活、心跳、输出上限、上下文和退出清理沿用已有机制，不因指标不好追加调用。

这是一轮控制变量补齐，不是新泛化确认，也不为“必须得到正增益”设目标。可记录+1pp作为研发上的实际收益参考，但区间跨0时只作探索结果；不声称40视频具有检出1pp差异的充分统计功效。

### P2：根据P1决定价值模块怎样改

| 新证据 | 下一步重点 |
|---|---|
| D与F相当或更好，FV也无稳定收益 | 优先检查事实质量、装箱和额外文本干扰；暂不扩建价值库 |
| F比D更好，FV仍弱于F | 最符合“事实有用，当前V有偏差”的情况；优先做相对价值证据对照 |
| D/F/FV共同弱于B0 | 先审查共同采样覆盖与选择接口，不能只改价值提示 |
| 改变导出就显著改变差值方向 | 先固定输出表达与评价协议，暂缓价值贡献结论 |

**价值分支的建议设计：让V回答“这个时刻相对哪个已观察时刻，多了什么值得看的证据”。** 保留五类，不设加权总分。条目应含候选/事实来源、对照片段或事实、可观察差异、观看作用和unknown；例如“较前一次尝试，这一次可见动作完成”比“动作很精彩”更可审查。当前帧不能支持比较时保留unknown，不补造进球、情绪或语音内容。

这应成为独立的V生成/表示对照，而不是再给已完成的相对提示换一句措辞。先用旧val10作机制开发，复用F事实和全部旧帧，不混入新采样、扩F预算、ASR、回看或边界修改。一个可行的后续公平小试是：同一批F与图像分别生成“绝对价值”和“带参照价值”的两个V包，各10次；用相同最终选择器各10次，共40次新调用，旧建库0次。两路生成预算、格式、来源名单、装箱与选择器相同，允许比较字段为空；唯一研究因素为价值定义是否要求可引用的相对差异。文本内容/长度仍会变化，不能称纯概念能力实验。

该分支仅为条件性建议，需P1结果后再冻结详细prompt/schema和完整清单；不与P1一次性启动。片头、logo或身份介绍不能被硬编码禁选；标题可能确有信息价值，也有含标题但整体改善的案例。修订的目标是证据与相对优先级，而非避开已知负例。

### P3：通过机制验证后才做新的确认

旧10仅开发；新40现在也已看过，不能回称未见验证。方法冻结后再用独立、按源视频固定的QVHighlights HD清单作查询高光确认，分别报告VeryGood mAP/Hit@1与TVSum Top-5 mAP，不把MR IoU当高光指标。具体清单、样本量和调用数另行准备，不自动启动QV、MR.HiSum、SVHighlights或QFVS。

## 5. 统计与因果检查

按ARS validate模式完成11/11项检查；“检查”不等于消除风险。

| 项目 | 本轮判断 |
|---|---|
| Simpson悖论 | 分开报告旧10、新40与全50；旧新方向不同不直接命名为Simpson悖论；未做类别层面的验证 |
| 生态谬误 | 统计单位为视频，不推断某类价值或每个推荐均有效 |
| 选择/Berkson偏差 | 保留固定全40；极端案例仅作说明，不构造成功子集 |
| 碰撞变量偏差 | 不按supported、合法率或改善情况筛效果分母；这些只是描述性变量 |
| 忽略基率 | Top-5 mAP不是二分类检错准确率，不能以supported比例推断价值精度 |
| 回归均值 | 不只重跑最差片段来证明改进；旧10到新40的变化不能单独证明过拟合或回归均值 |
| 幸存者偏差 | 本轮全部400成功；未来故障与未尝试保留完整分母 |
| 多重寻找 | 只有既定FV−F是原主比较；新增文本/时间模式为探索，没有新增显著性检验 |
| 分析自由度 | 旧协议和所有口径保留；新导出独立版本，不按成绩选参数 |
| 相关当因果 | 文本理由传播、记忆丢失与掉分不自动构成根因；F−B0存在方法和模型混杂 |
| 反向因果 | GT在冻结预测后评价；未将结果、审查标签或跌幅作为模型输入；事后模式仍需对照 |

Bootstrap只刻画本批视频配对差异，未验证对其他视频类别、标注习惯或模型采样的可推广性。没有重新运行模型，不能标为完成随机性复现或独立语义验证。运行日志中张量维度启发式警告的数值影响也未专门验证，不用它解释指标下降。
