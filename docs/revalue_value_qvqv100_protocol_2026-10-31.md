## 固定范围与问题

沿用已冻结 100 条 query、REZE Direct 的全部 139 个有效候选以及 v1.1 的旧帧像素、PTS、region、次序。两条 base 无候选 query（9160、2498）保留在总体分母，不能补造候选。每候选每臂一次，共 **278 次**，零重试。顺序按原候选清单，两臂成对相邻，随候选序号交替 Q/QV 谁先执行；批次 10 请求，不按旧成绩选子集。

目标是检验具体价值证据提示相对于普通 query 条件核查的增量；原区间、分数、排序不变。只有语义核查，无新增边界分支、记忆、回看、采样、ROI、音频、训练或模型更换。

Q+V 唯一额外输入是冻结题库对已适用维度的支持、反证、unknown、禁止推断提示；无新增必要条件、不同 schema 或单独判定阈值。Q 不显示维度名称，两臂都能通过相同 CPU 映射生成五维证据视图。提示长度与注意力变化是不可避免的共同变化，不宣称纯价值概念因果识别。

没有适用价值维度的 query，两臂提示逐字相同，不附加空价值块；这类样本仍按固定清单在两臂各执行一次、保留分母，提供同提示重复的一致性参照，不按结果剔除。逐条提示相等性由 CPU 准备收据记录。

## 模型、资源与独立记账

固定本地 `Qwen3-VL-8B-Instruct`，修订 `0c351dd01ed87e9c1b53cbc748cba10e6187ff3b`；vLLM 0.12.0、bf16、单卡、eager、seed=0、temperature=0、top_p=1、top_k=-1、thinking关闭，旧图像不resize。不加载外部模型或付费 API。

| 独立上限 | 数量 |
|---|---:|
| 正式尝试（含失败） | 278：每臂 139 |
| 额外故障尝试 / 自动重试 | 0 / 0 |
| 绝对实验 token | 3,416,064（278 × 12,288）；实际输入另由 CPU 逐条计量 |
| 输出 token / 请求 | 2,048 |
| 同时 GPU | 最多 1 张空闲 RTX 4090 |
| worker 启动 | 最多 28，启动失败也占名额 |
| 每 worker GPU 生命周期 | 600 秒，含加载、生成及清理 |
| 累计 GPU 生命周期 | 16,800 秒（4.667 GPUh） |
| 空闲卡等待 | 一次队列累计最长 24 小时；等待不分配 GPU |

这些是依据完整范围设定的本轮运行上限，不是旧余额转入。每次调用前预留完整 prompt+output_cap；返回 token 可核验时按实际计账，未知失败保留预留。未尝试项保留。无候选不产生请求。文本契约由当前助手编写，无额外实验模型生成调用。

CPU 审查发现模型配置为 36 层、8 个 KV heads、head_dim=128；BF16 KV 理论每 token 147,456 字节。沿用旧 2 GiB KV 配置，不能容纳初拟的 16,384 上下文，因此在任何运行/冻结前改为 12,288，并相应收紧总 token 上限。CPU 逐条检查输入+输出不超限，不截帧。这是预运行修订，未发生 OOM 或模型尝试。

GPU 仅在 NVML 显示无计算进程、显存 <512 MiB、利用率 <5% 且 PCI 映射一致时使用。vLLM 0.12 使用数字设备掩码：设置 PCI_BUS_ID 排序，并在模型加载前核验实际 GPU UUID。不给其他进程发信号，不改依赖或权限。

- 运行时错误/OOM、启动失败、预算/生命周期超限、终态不能确认：停止；无重试和自动恢复。保留原始响应和全部收据。
- 纯 JSON、引用或逻辑 invalid：保存并继续后续固定样本，避免按好坏中途挑数据；不重问。
- 无空闲卡：CPU 等待，状态为 queued，GPU/worker 为 0。24 小时到期则结束等待并报告，不重新排队。
- 单次 supervisor 防重复锁；只有所属 worker 进程组可在其终止或预定硬时限清理。不能据第三方日志干预其他任务。
- 科学指标不控制运行中采样。全部模型进程退出、账本与响应冻结后，CPU 评价器才读取 GT。

## 评价与结论边界

两臂按相同 139 候选分母报告合法率、flagged/supported/insufficient/invalid、IoU<.5 代理 precision/recall/误报，并列 .3/.7 敏感性及固定时长规则。100 query 全部列出，两条空 base 单列。按同候选统计判定与条件状态变化，按 source video 对两臂配对 bootstrap；不把技术失败视为 unknown 或正确结果。

仅合法输出统计模型条件状态，NA 是契约映射结果，不能称为模型价值检出率。主要语义效果仍需独立人工证据标签；IoU 代理包含边界/覆盖误差，不等同于错事件。该语义分支不处理纯边界错误。原正式探索门槛（138/139合法、precision≥80%且高于错误基率、recall≥30%、误报≤10%、insufficient≤40%、flag≥20）仅原样列作诊断参照；不得将其通过包装成价值增益或定位提升。

若 Q+V 仅使字段更满，不能认定有效；若不减少有证据的错误或增加误报，不扩大方案。没有预先独立人工标签时，只报告代理结果和待审查案例，允许无收益/负结果。
