# ReVALUE 当前实验进度与结果

> 截至北京时间 2026-11-02 23:56。面向组会汇报，重点覆盖 10 月 30 日至 11 月 2 日的 grounding 基线、verifier 修复与 Q/Q+V 对照。本文是当前状态快照，不替换原协议、预测或失败记录。

## 1. 当前结论

**输出契约的可靠性已明显改善，但检错召回仍低，价值引导的收益尚未确立。** 最新 8B 实验完成 278/278 次调用，归一化后 273 条输出合法；Q 与 Q+V 分别检出 6、8 个低 IoU 候选。32B 权重及输入准备已完成，但首次三卡启动失败，尚无模型预测结果。

研究主线是 **grounding：检验 query 所描述的内容是否出现在预测区间内，以及区间是否定位准确**。当前 verifier 只验证内容条件，尚未执行边界修正、重新排序或定向回看，不能将检错结果表述为最终定位指标提升。

## 3. 最新 Q / Q+V 对照结果

### 3.1 这次比较了什么

- **Q**：根据 query 拆出的条件，检查人物、物体、动作、关系等是否得到证据支持。
- **Q+V**：沿用同一套条件，加入适用价值维度的具体判断指导，包括结果、信息、情绪、动作和感官特征。
- 固定候选、缓存帧及 PTS、query 条件、模型、输出结构与验收规则；主要干预是价值维度的提示指导。

价值维度的适用性由冻结条件映射确定，不是模型重新发现的标签；`not_applicable` 不等于漏检。全部 query 条件由助手仅依据 query 构建，尚未经过独立人工审校。

### 3.2 主要结果

两组均以全部 139 个候选为分母。下表将与任一 GT 的最大 IoU < 0.5 作为错误代理，共 85 个；另外 54 个为代理正确区间。**低 IoU 不必然等于内容语义错误**，也可能来自边界、覆盖范围或标注差异。

| 指标 | Q | Q+V |
|---|---:|---:|
| 合法输出 | 136/139 | 137/139 |
| 无效输出 | 3 | 2 |
| 判断支持（supported） | 70 | 63 |
| 证据不足（insufficient） | 59（42.45%） | 64（46.04%） |
| 报警（flagged） | 7 | 10 |
| 代理正确报警 / 误报 | 6 / 1 | 8 / 2 |
| 报警精确率 | 85.71% | 80.00% |
| 错误召回率 | 7.06% | 9.41% |
| 代理正确区间误报率 | 1.85% | 3.70% |

Q+V 相比 Q 净增加 **2 个代理正确报警、1 个误报**，召回提高 2.35 个百分点，但证据不足也增加了 5 个。报警数量少、没有独立人工语义标签，现阶段不足以证明价值引导具有稳定收益。两组均未通过原探索性门槛。

已有冻结 CPU 时长规则检出 31 个代理错误、误报 9 个，召回为 36.47%、精确率为 77.50%。它更容易捕捉过长区间，但误报率也更高，不能用它替代语义检验。这个对照提示：需要区分“内容不匹配”和“边界/覆盖有误”。这里引用已有评价，未调整规则。

### 3.3 工程改进与模型能力要分开

本阶段已加入事实与帧引用绑定、依赖条件检查、生成顺序约束，并对普通引用中的完全重复项稳定去重。旧 v2.2 响应用同一 v2.4 验收规则离线复核后仍有 23 条无效，新 v2.4 为 5 条；这是工程修复结果，不是单独某一项改动的因果收益。

本次 278 条原始响应中，严格不去重时有 52 条不合法；去重恢复 47 条，最终合法率为 **273/278 = 98.20%**。因此，合法率提升有验收归一化的贡献，不能全部归因于模型更会引用证据。

剩余 5 条失败为：2 条输出达到长度上限、JSON 不完整；3 条声称确定时间顺序，却未提供两个有序事实。未定义引用、重复事实定义及时间顺序证据仍严格检查，不通过删除证据或改写答案来恢复合法性。[完整结果与验收审计](revalue_value_qvqv100_v2_4_results_2026-11-02.md)

## 4. 尚未解决的问题与具体例子

**第一，引用合法不等于事实正确，也不等于事实能支持结论。** Q 判为 supported 的 70 个区间中仍有 41 个低 IoU；Q+V 为 63 个中的 32 个。这些是待审查项，不能全部直接标为语义漏检。

例如 qid=9572，query 要求“男子横持手机阅读文章”，候选为 28–37 秒。模型响应描述了可读文字和带字幕的视频，却把它用于支持“文章”条件。这里存在证据到结论的语义跳跃嫌疑；文章也可能包含视频，仅凭文字响应不能确认实际定位错误。

**第二，模型仍可能自行扩大条件依赖，造成不必要的 unknown。** qid=10 要求“女子在盆栽旁独白”，候选为 0–150 秒。模型因无音频无法确认独白，又把“植物是否在盆里”的判断依赖到独白条件；但冻结条件中该项的 `depends_on=[]`，模型自己的事实描述也多次提到盆栽。这是响应内部的依赖不一致，不是独立人工确认画面内容。

**第三，内容正确性与区间准确性尚未拆开验证。** 一个过长区间可以确实包含 query 事件，同时因夹杂大量无关时段而低 IoU。当前 semantic-only verifier 可能判 supported；这并不证明它完成了 grounding 验证。

**第四，证据不足尚无补证闭环。** 两组超过四成候选为 insufficient。当前没有通过新帧、定向回看或其他模态补足证据。不能把 unknown 直接转为错误，也不能以减少 unknown 本身作为质量提升。

Qwen3-VL-32B-Instruct 的 14/14 个权重分片已下载并校验。278 个请求的候选、像素、提示、schema 等完成与 8B 条件的一致性检查，运行器通过 145 项 CPU 检查及源码审查；这些检查不等于实际显存启动已成功。

**11 月 2 日 22:59 首次使用 GPU 0、2、3 启动后失败，当前不是仍在排队。** 日志记录两类问题：

1. 调度器的进程归属检查报 `Process token/run ownership changed; refusing cleanup`，随后停止派发。触发机制尚未定位，不能直接认定为某项环境变量问题。

## 6. 下一步建议与完成标准

以下是后续建议，本次仅整理报告，没有实施新实验。

| 优先项 | 要解决的问题 | 应提供的证据 |
|---|---|---|
| 排查 32B 启动失败 | 显存准入与进程归属检查阻断执行 | 明确失败来源；任何运行配置变更重新审查并版本化，保留零重试失败轮次 |
| 审校 query 条件与依赖 | 模型把局部事实判断错误地绑定到其他条件 | 固定案例，区分单项可见事实与整体 query 是否成立；依赖传播由代码按合同执行 |
| 建立小规模独立语义审查 | IoU 代理无法区分内容错、边界错、标注争议 | 同时覆盖报警、supported、insufficient、invalid，记录分歧与证据边界 |
| 设计定向补证对照 | 已有稀疏帧不足以确认关键条件 | 比较旧帧、等量均匀新帧、等量定向新帧；固定模型与问题，不同时加入裁剪、音频和边界改写 |
| 单独验证边界与覆盖 | 当前 verifier 未检查完整 grounding 目标 | 分别报告内容判断和时间覆盖；最终如改写区间，再测 R1 与 MR mAP |

优先目标是说明“哪类错误可以稳定发现、缺什么证据、补证是否有效”。继续增加价值提示长度或更换更大模型，都需要独立对照支持，不能提前写成方法收益。新补证实验需要另行冻结范围和预算；本报告不构成执行许可。
