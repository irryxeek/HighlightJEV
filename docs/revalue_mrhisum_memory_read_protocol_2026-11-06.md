## 固定范围与条件

固定历史`reze_mrhisum_full1888_v2/plan.json`的`selected_ids[:40]`；该顺序源于sha256("42:"+video_id)。选择不读GT或成绩，保留全部40分母。它是历史可用1888视频中的开发诊断子集，不代表官方2000视频全量。

- B0：旧Qwen3-VL-8B REZE完整1秒曲线，重新从缓存Yes/No概率核对；零新增B0调用。
- B0_5s_flat：CPU导出参照。依官方float32按连续5秒取均值，尾段保留，再广播回完整1秒网格。
- D：27B只看固定图像和共同高光提示，无文本记忆。
- F：相同图像、模型、提示，加入旧轮转读取的事实记忆。
- F-read：仅改变F块及对应可引用事实ID集合；优先补充候选片内、最近前后背景、事件族和帧覆盖，保持时间组/不确定性底线，仍按原库顺序呈现。

每视频一次共享建库：从旧REZE已读帧选64个全局均匀时间目标的近邻，每8帧一组，共8次调用。建库保留完整F/V原始输出；本轮选片不输入V字段，不增加价值提示变量。全部三组选片都看同一64全局帧加旧B0五个候选各最多4帧，去重后不超过84帧。短尾候选不足4个旧帧时用全部可用帧；不复制帧、不替换视频。全程保留旧模型像素与真实PTS，重解码并核对完整原窗口RGB SHA256；不使用新视觉采样或回看。

模型为Qwen3.8-27B BF16，固定revision `1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0`，TP=4，temperature=0，seed=0。既有环境不改依赖。由于Mr.HiSum旧帧包含480×864，三组统一将engine image上限设84×864×480、context=49152；CPU逐请求核验实际像素、token及grammar，任何越界先停止，不能静默缩图或换小模型。

## 原生输出与评价

候选和choice ID使用5秒网格：第j格为[5j,min(5j+5,N))。用既有0.5秒局部证据容差预绑定实际帧；ID合法仅证明来源映射，不证明语义正确。每条输出至多5个分层建议，允许同分、少选、弃权；这不是Mr.HiSum官方摘要长度。

复用稳定提升导出：把建议格前移，同层保留B0顺序，再按降序重新分配原5秒分数multiset；不制造新分差。广播每格得分到其1秒位置并截到N秒。无建议、无效、缺依赖、未尝试均完整保留，回退B0_5s_flat并单列状态，不能称作新模型预测。原B0永不覆盖。

预测冻结后才打开官方H5。主报告mAP50和mAP15：按作者float32五秒平均、GT最高floor(50%)/floor(15%)、exp归一化与sklearn AP。次指标使用原KTS分段及15% knapsack的summary F1，不修订作者端点约定。额外列Constant分数CPU参照；不作为新模型条件。

主比较F-read−F按全部40视频配对，10000次bootstrap，seed42；同时报告上下/平局、合法率、回退、实际读入条目变化。原B0和B0_5s_flat的差异须报告：平坦化可能改变摘要F1；5秒再平均也可能出现float32舍入，不能暗改官方评价抹掉差异。
