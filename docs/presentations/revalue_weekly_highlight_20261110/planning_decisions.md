# Delegated presentation decisions

## Stage 1 — communication and template decision

- Authority: current user asks to create the PPT from the just-approved group-meeting summary. Apply the user's persistent delegation: “按推荐目标，设计细节由你决定，直接完成（推荐）”. This is an agent design decision under delegation, not a new user/UI confirmation receipt.
- Audience: 导师与研究组，熟悉 ReVALUE，关心方法贡献、实验依据和下一步取舍。
- Communication intent: 汇报本周已完成的方法与实验，解释均值提升和负结果，明确尚未验证的机制及下一步优先事项。
- Audience outcome: 能区分记忆路线与通用评分路线、全50与后40的版本范围，理解五维价值尚无稳定收益，并讨论优先修复的问题。
- Core message: 事实保真与决策目标值得继续优化；五维价值的额外收益仍未确认，不能以小样本提升代替完整验证。
- Delivery context: 中文组会现场，约8–10分钟；会后可凭备注复查证据。
- Artifact afterlife: 可编辑PPTX、逐页讲稿、来源归档和可重复导出源码。
- Content divergence: 未另作约束，依汇报内容重组；数字、范围与结论强度遵循本地冻结报告。
- Canvas: ppt169，1280×720。
- Template mode: free_design。延续本会话的海军蓝、青绿、赭橙学术配色，不选择外部模板。
- Page range: 10–12；resolved count planned: 10。

## Stage 2 — solution intents before catalog selection

1. Evidence-first research update: 用两条工作路线建立共同地图，依次呈现系统对照、全量评分、失败案例、修订效果和验证边界；图表和比较结构承担主要信息。
2. Failure-driven case narrative: 从两个高分误选案例切入，倒推旧评分目标，再呈现新目标与跨数据集反例；照片/案例占主导。
3. Review-board matrix: 以模块、证据和待验收项为矩阵，每页回答一个模块是否贡献，表格和状态编码占主导。

Preferred intent: 1。它最贴合已批准的两段汇报，既覆盖本周工作，又能用统一证据口径解释当前结论。

Production: continuous；Design Spec depth brief；Speaker Notes enabled；Custom Animations disabled；Narration Audio disabled；refine-spec disabled。
Images: none proposed after full-roster review. The page jobs are method relationships, numerical comparisons and documented failure records; no real-world subject recognition is necessary. Use editable data and native evidence text rather than illustrative photography.
