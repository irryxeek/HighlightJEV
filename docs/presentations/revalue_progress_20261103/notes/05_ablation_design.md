Q 组根据 query 条件检查人物、物体、动作和关系。Q 加 V 使用完全相同的条件，额外提供结果、信息、情绪、动作和感官五类适用视角的判据：什么可以支持、什么是反证、什么仍然缺证，以及哪些推断不成立。

两组固定候选、帧像素与时间戳、模型、query 条件、schema 和验收。每组一百三十九次，一共二百七十八次，零重试。五维视图由条件映射得到，不是另外让模型打五个分再加权。某个维度不适用，只表示这个 query 没有对应要求；不能直接称为漏检。条件由助手仅看 query 构建，尚未经过独立人工审校。价值块带来的提示长度和注意力变化也一起发生，所以测的是整个提示包，而不是抽象价值概念的纯因果效果。
