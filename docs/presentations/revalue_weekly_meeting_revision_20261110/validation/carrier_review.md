# 页面载体复核

16页的主要任务与实际载体一致：四个数据图、两个语义表、两个完整输入帧联系表均存在，两个案例图的画面与原标签保持完整。比较、机制、流程、诊断、状态与结尾采用不同阅读路径。

- Carrier / field轮廓：同一数值基线、表格行列及矩形原图承担数据和证据归属；另加切角、牌匾或折叠轮廓会给条件或病例暗示未经来源确认的状态，因此采用无形变的平面数据区域。
- Direction / sequence：P04用四个原生rightArrow表明真实处理先后；P05的三层问题、P14的阶段、P15的下一步用纵向对齐与编号表达顺序，连接线和所有权范围明确。
- Grouping / ownership：表格、同一图表框与病例旁注已定义归属；额外括号或框架不会增加事实、判断、候选A/B之间的可辨识关系。
- Emphasis / annotation：直接标注数值、风险色与P15的行内强调承担重点；没有需要指向图内细节的悬浮气泡，病例原始时间标签保留。
- Gradients=0：共同零基线、清晰类别与平面色块提供数值对比，不使用会被读成额外连续量的渐变。
- Filters=0：原输入帧必须保留可观察性，病例图完整显示；其他证据为原生图表与文字，无需景深或模糊处理。
- Icons=0：计划未注册图标池；具体实验条件、数值、原图与阶段编号已承担辨识任务。

这是一份设计实现复核，不是实验效果验证或独立人工语义标注。
