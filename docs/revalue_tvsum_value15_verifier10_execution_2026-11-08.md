## 已完成的修改

C 组保留原提示词、schema 和解析行为，重新运行作为同期对照。V15 保留既有通用高光五维题库，每侧回答 O1–O3、I1–I3、E1–E3、A1–A3、S1–S3，合计 30 项／候选对。

单项以 `[状态, 帧ID列表, 简短依据或缺证]` 保存；s/c/u/n 分别表示支持、正面反证、证据不足、不适用。明确回答必须有本片段可见来源；相对判断还需要可区分的参照，最终胜出依据必须与双方比较帧对应。贡献依赖事实支持，优先级依赖已支持的贡献。未知不变成反证；一个维度未知也不否定其他维度已有的正面证据。

单维反证不足以推出整体“无贡献”：整体负面要求至少一个贡献项有反证，其余均为反证或不适用；仍有未知且没有正面支持时保留证据不足。只对重复普通引用 ID 稳定去重，不修写语义判断，原响应始终保存。

为共享原 1536 输出 token 上限，V15 单题依据≤40字符，候选观察／理由／缺证各≤64字符，比较依据／缺证各≤80字符。普通组原长度规则不变。这些输出空间分配、逐项证据与依赖检查都是干预的一部分，不能称纯“价值概念”单因素测试。
