## 问题和改动

上一版在后40条得到53.5694 Top-5 mAP，REZE为53.2858。低AP案例显示：可观看、主题相关、标识清楚的片段不一定比主线关键步骤优先；但尚不能认定这些现象是整体差异的单一原因。

本轮只重评分一个新条件 `core_8B`，联合修改：

1. 最终 Yes 目标从可观看/实质贡献收紧为：对主线的关键步骤、代表性核心行为、关键事实、有意义结果或显著变化有直接可见证据。
2. 品牌、名字、地址、联系方式、门面、一般场景单独只能支持身份或环境，不能直接支持关键贡献。可读文字不自动重要；实质步骤、诊断信息、关键结果仍可成立。不能一概排除文字、静态画面、品牌出现的真实事件。

五类是可替代路径，一个充分支持的关键贡献即可 Yes；不是五类全部成立。结果、情绪、动作三维原文保持不变。不强迫 Yes、分差、全局新颖性或比较胜负。背景仅解释局部角色，不能证明局部未见事件。

这是两个授权改动的**联合条件**，不能分别归因最终目标或品牌门槛。提示长度随规则变化，模型注意力分配也可能变化。

## 固定范围与控制

- 固定历史 `rows40.json` 全40视频，与开发10不交叠；两分片仍为原顺序偶数/奇数索引，各20视频。
- 全2953个原3秒窗口：1515 + 1438。逐窗口验证旧像素哈希和真实PTS，沿用2fps/最多6帧、旧视频解码与原生处理设置。
- 同一 Qwen3-VL-8B-Instruct、本地权重、bfloat16、单卡TP1、seed0、单token Yes/No、原logprob转换。旧逐秒映射与2秒评价网格不变。
- 原已生成的每视频事实背景逐字节复用，背景新增调用0。
- 对照为已完成报告 `all_models_report_v2` 的 REZE_8B 与 revised_8B；控制预测冻结复用，不重新推理。
- 不加入6秒间隔、事件去重、候选替换、解释生成、回看、27B或其他数据集。
- 新版单token评分不能指出实际使用哪条价值规则。旧低AP五例在准备时固定作解释性回访，不能替代完整40条统计。

本批40条已被上轮结果和失败诊断查看，属于开发反馈后的条件验证，不是独立未见测试集。新实验输入不含GT、官方标题或旧分数。

## 评价、质量与停止条件

先保存所有预测、源代码和哈希，再由独立CPU后处理读取固定标注。主指标沿用冻结UMT Top-5 mAP，独立实现与作者代码交叉核对。每视频为配对单位，报告新版−当前修订版、新版−REZE的均值、95% bootstrap区间（10000次、seed42）和升/降/同数量。

技术完成要求：40/40完整、2953/2953请求、原帧/PTS一致、概率与原生token契约通过、两个worker正常退出、预算不超限。任何错误停止所属worker，无自动补跑；其他独立分片可以完成。失败和未尝试的视频仍保留全40分母，缺失曲线保持null；零失败信用不能解释为模型性能。

没有按中途mAP、Yes率或旧GT早停，不改变阈值，不挑成功子集。均值提高仅说明本批结果；配对区间跨0时不能声称稳定改善。两个比较未经多重校正，均为描述性。即使提高，也不能证明五维都有用或泛化到其他数据。
