# 通用高光评分 v1：TVSum val10 与 REZE 配对结果

## 结论

10/10 视频、1,260/1,260 窗口完成，零失败、零重试。新方法 Top-5 mAP 为 **57.8566%**，旧 REZE 为 **61.3167%**，差值 **−3.4601 个百分点**。5 条提升、5 条下降；按视频配对 bootstrap 的 95% 区间为 **[−19.2607, +12.9474] pp**，跨过零。本轮没有证据表明该提示修改带来稳定收益，也不能据此认定五维价值机制无用。

这是此前用于开发的官方 UMT val10，**不是独立未见测试集，也不是全50视频结果**。本轮已经结束，没有自动追加实验。

## 本次实际测试了什么

对整条视频的全部连续3秒窗口逐个评分，每个完整窗口采样6帧（2 fps）。Qwen3-VL-8B-Instruct BF16 输出单个 Yes/No，读取二者 token 概率，沿用 REZE 的窗口→1秒→2秒分数导出及 UMT Top-5 mAP。Top-5 是评价时从完整时间轴取出的前五个2秒片段，并非只推理五个候选。

新条件把原动作核验问题改为“当前可见片段是否有值得保留在短高光摘要中的具体理由”，提供结果变化、可见信息、反应、动作和视觉揭示五类可选例子。这是**一个整体判断**，没有独立五维分数、加权、记忆、比较器、回看或边界细化。旧分数、标题、语音和标签不进入评分器。

对照复用旧 REZE 的原始缓存。本轮全部1,260窗口的模型输入像素哈希、帧索引、实际 PTS 均与旧输入一致；旧 top-20 概率读数与完整分数曲线均成功复算。模型版本、采样、读数和评价固定；新提示每次增加124 token。旧缓存不是同时重跑的对照，模型启动与调度配置不完全相同，不能声称排除了所有运行数值差异。结论针对这版任务提示整体，不归因于某个价值维度。

## 输出诊断：有区分，但未稳定选得更好

- **不存在整视频同分退化**：新方法10条均产生不同片段分数；10条的 Top-5 集合全部发生变化。
- **不存在概率缺失回退**：两组所有1,260个窗口的 top-20 均包含 Yes 和 No；本轮原始输出969次 Yes、291次 No，没有其他词或解析失败。
- **认可范围明显变宽**：新方法窗口均值0.7460，REZE为0.0988；分数≥0.5的窗口为1,006/1,260（79.84%），旧方法为71/1,260（5.63%）；新方法495个窗口≥0.95。
- **仍有局部同分**：新方法1条、旧方法2条视频在第5/6名边界同分，沿用相同官方排序实现，不人为破同分。这与此前四态比较全部 tie 是不同现象。

整体概率上移本身不能解释排序指标下降，单纯提高阈值也不会改善无阈值的 Top-5 排序。实际问题是被排到前面的片段发生了较大变化，视频间收益不稳定。例如 J0nA4VgnoCo 的前五集合完全替换且下降51.69 pp，而 Se3oxnaPsz0 提升51.04 pp。以上是指标案例，**尚未进行新的画面人工复核，不能直接解释为具体价值误判或数据标注问题**。

下一步建议先离线对照这两个方向的原帧与新旧高分窗口，检查模型认可的局部理由是否等同于标注者关心的高光；保留完整10条统计，不据此挑选有利验证子集。当前结果不支持直接扩到50条，也不支持同时加入记忆、回看等多个修改。本报告仅提出建议，未启动后续运行。
