# TVSum 最新实验前端接入（2026-11-10）

本轮为已有实验结果的只读页面更新。默认展示11/10全50视频的8B/27B窗口评分，另外提供11/09核验40视频、11/07事实保真40视频和11/06历史读取对照。没有启动或恢复实验。

## 页面入口与内容

- 沿用服务器127.0.0.1:8765、8766，路径`/tvsum`；在原SSH端口转发下刷新页面即可。
- 左侧切换实验批次、固定样本范围及Top-5/mAP15/mAP50；逐视频表同时展示三项AP和保存的实际Top-5。
- 两侧播放同一原视频的不同方法片段。窗口评分为3秒，最终评价为2秒格；逐次记录中的窗口和Top-5分别标注，不把窗口当GT。
- 评分组可选择每个窗口，查看原始Yes/No概率、当时6帧缓存、背景及冻结提示模板；模板源码不冒充展开后的原生多模态wire。新旧8B条件的本接口提供冻结窗口读数，27B额外展开逐次原始响应。REZE为8B对照，没有同轮27B REZE。
- 核验组每视频5对，显示普通核验、旧V15、修复V15及F-local参照。逐题支持/反证/不足/不适用、来源帧、实际事实文本、替换动作和invalid原响应均保留。invalid不显示成通过契约的答案。
- 新记忆组的F-local/FV-local展开实际输入记忆、原始选择提示和响应；历史条件未接入的中间文本明确显示来源限制，仍可比较完整冻结分数。

## 指标与科学边界

Top-5沿用旧UMT评价。mAP15/50读取`revalue_tvsum_map15_map50_supplement_2026-11-10.md`对应冻结结果：原2秒格、20人GT均值最高比例二值化、全片sklearn AP。不是IoU阈值，也不与HiVid或Mr.HiSum不同协议数字直接横比。

核验slot-rank与记忆native导出分列。失败、弃权和原回退不删改；前端不重新评分、排序、裁剪或解释旧失败。所有视频均为已用于开发的样本，full50包含UMT训练划分。

## 来源校验与访问边界

后端只读取冻结预测、保存评价、CPU补算收据及原媒体。评分/评价来源由补算清单SHA256绑定，实验rows/cache/background/提示由原manifest绑定。记忆和核验响应核对原账本记录哈希；27B窗口原响应与冻结窗口概率做精确一致性检查，并注明当前读取SHA256不等同于原实验逐响应哈希收据。

图片来自既有NumPy缓存，仅在内存编码PNG；不新采样。媒体路径来自固定视频清单，支持Range。新增API只有GET；POST/PUT/PATCH/DELETE拒绝。没有导入torch/vLLM，没有推理或重试接口。
